# Problem Statement

## Title
**Expense Tracker using Python**

## Objective

The objective of this project is to develop a simple menu-driven Expense Tracker application using Python that helps users manage their daily expenses efficiently.

## Problem Description

Managing daily expenses manually can be difficult and time-consuming. People often forget where they spend their money, making it hard to monitor their spending habits.

This application provides a simple solution by allowing users to:

- Record new expenses.
- Store expense details.
- View all recorded expenses.
- Calculate the total amount spent.
- Search for a specific expense by name.

## Functional Requirements

The application should provide the following functions:

1. Add a new expense.
2. Display all expenses.
3. Calculate the total expenditure.
4. Search for an expense using its name.
5. Exit the application safely.

## Input

The user provides:

- Expense Name
- Expense Amount
- Expense Category
- Menu Choice

## Output

The program displays:

- Confirmation after adding an expense.
- List of all recorded expenses.
- Total amount spent.
- Search results.
- Appropriate messages for invalid inputs.

## Tools Used

- Python 3
- Console-based interface

## Conclusion

The Expense Tracker demonstrates the practical use of Python programming concepts such as functions, lists, dictionaries, loops, and conditional statements while solving a real-life problem in a simple and user-friendly manner.
