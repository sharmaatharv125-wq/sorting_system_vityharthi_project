# 💰 Expense Tracker (Python)

## Overview
Expense Tracker is a simple Python console application that helps users record and manage their daily expenses. It allows users to add expenses, view all recorded expenses, calculate the total amount spent, and search for a specific expense by name.

This project is designed using basic Python concepts such as functions, lists, dictionaries, loops, and conditional statements.

## Features
- Add a new expense with name, amount, and category.
- View all saved expenses.
- Calculate the total money spent.
- Search for an expense by its name.
- Easy-to-use menu-driven interface.

## Technologies Used
- **Language:** Python 3
- **Concepts:** Functions, Lists, Dictionaries, Loops, Conditional Statements
